
# Southtown Plant Co. – Week 2 Developer Handoff

## Changed → Why

### 1. HTML Structure and Accessibility

**Changed:** I added the HTML5 `<!DOCTYPE html>` declaration and updated the page language to `lang="en"`.

**Why:** These changes help browsers read the HTML correctly and allow screen readers to identify the language of the website, making it more accessible.

### 2. HTML and CSS Organization

**Changed:** I moved the background and text colors from the HTML into the CSS stylesheet.

**Why:** Keeping the styling in CSS makes the code cleaner and easier to manage. If another developer needs to change the colors later, they can do it in one place instead of searching through the HTML.

### 3. Navigation Accessibility

**Changed:** I corrected the navigation link colors to improve visibility and contrast against the background.

**Why:** This makes the navigation easier to read and helps visitors see the links more clearly, including when hovering over them.

## What I Intentionally Did Not Change

I kept the original client content, general color palette, and fixed-width layout. The goal for Week 2 was to clean up the existing code without redesigning the website. I wanted to preserve the client's original design while preparing the project for the responsive updates in Week 3.

## Next Sprint

For Week 3, I plan to work on making the website responsive so it adjusts to different screen sizes, including phones and tablets. I will also improve the navigation so it is easier to use on smaller screens while keeping the original design consistent.
